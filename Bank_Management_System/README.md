# Bank Management System

## Project Overview

This is a beginner-level Bank Management System developed using Python and Object-Oriented Programming (OOP).

It allows users to create bank accounts, search accounts, deposit money, withdraw money, and view transaction history.

## Features

* Create new bank accounts
* Search accounts using account numbers
* Display account details
* Deposit money
* Withdraw money
* View transaction history
* Handle multiple accounts
* Menu-driven interface

## Technologies Used

* Python
* Object-Oriented Programming (OOP)
* Lists
* Functions
* Loops
* Conditional Statements

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:


py Bank_Management_System.py

## Current Limitation

Account information is stored in memory. Data resets when the program exits. Permanent file-based storage is not implemented yet.
